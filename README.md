## 📌 Project Overview

This project focuses on **Google Play Store Data Analysis** using Python, Excel and Power BI.

The objective is to analyze mobile applications available on the Google Play Store, identify trends and patterns, and transform raw application data into meaningful business insights through data cleaning, exploratory data analysis and interactive dashboard visualization.

The project demonstrates an end-to-end **Data Analytics workflow**, starting from raw Excel data and progressing through Python-based analysis to an interactive Power BI dashboard.

---

## 🎯 Project Objectives

- Analyze Google Play Store application data
- Clean and preprocess the dataset
- Handle missing and inconsistent values
- Explore application categories and ratings
- Analyze application installs and reviews
- Study free vs paid applications
- Analyze application pricing
- Identify highly rated applications
- Understand category-wise trends
- Build an interactive Power BI dashboard
- Generate meaningful business insights
